🍽️ Kenyan Snacks • Emoji Ordering App

A clean, iPhone-style web app that lets users browse, select, and “order” Kenyan street foods using emoji-based visuals. The project demonstrates modern UI design, interactive state management, data storage, and dynamic rendering — all running 100% client-side with no backend.


---

🚀 Live Demo

🔗 https://cadeau3.github.io/Kenyan-Snacks-Emoji-App/


---

📱 Overview

This project recreates a realistic mobile food-ordering experience using only HTML, CSS, and JavaScript.
The app features:

🍩 Emoji-based food thumbnails

🧭 Category tabs (Snacks, Desserts, Meals, Coastal, Breakfast)

🛒 Interactive cart with quantity controls

🧮 Automatic totals + tax calculation

💾 Save, load, and delete past orders (localStorage)

📤 Export orders to CSV or JSON

💡 Fully responsive, smooth iPhone-like UI
