# Kenyan Snacks • Emoji App

A lightweight, iPhone-style food ordering experience built entirely with HTML, CSS, and JavaScript. The app showcases popular Kenyan snacks and meals using expressive emojis, allowing users to browse categories, build a cart, calculate totals, save orders, and export their data — all offline, fully client-side.

### 🔗 Live Demo  
https://cadeau3.github.io/Kenyan-snacks-app/

---

## Features
- 🍽️ Emoji-based Kenyan food menu  
- 🧭 Category navigation (Snacks, Meals, Breakfast, Desserts, Coastal Foods)  
- 🛒 Interactive cart with quantity controls  
- 💵 Auto subtotal, tax, and total calculations  
- 💾 Save orders to localStorage  
- 📤 Export cart as CSV  
- 📱 Mobile-optimized iPhone-style interface  

---

## Tech Stack
- HTML5  
- CSS3  
- JavaScript (ES6)  
- LocalStorage  
- GitHub Pages hosting  

---

## Purpose
This project demonstrates UI/UX design, dynamic rendering, data handling, and cultural creativity by turning everyday Kenyan foods into an interactive digital tool.
